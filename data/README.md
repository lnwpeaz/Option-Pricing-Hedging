# Data policy

The first version uses synthetic GBM scenarios generated from explicit configurations.
No market dataset is bundled, fetched or required. Save input parameters and seeds with runs;
store one representative path ledger rather than every large intermediate array by default.

data/external is reserved for later licensed or public inputs. Record source, acquisition UTC,
license, quote timing, units and checksums before using external data. Do not mix external
market observations and synthetic values without labeling each source.
